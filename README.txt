LPK Group Website

Cách sử dụng:
1. Giải nén file ZIP.
2. Mở file index.html để xem website.
3. Thay hotline, email, địa chỉ và website trong file index.html bằng thông tin thật.
4. Upload toàn bộ thư mục lên hosting hoặc gửi cho bên làm web để triển khai.
